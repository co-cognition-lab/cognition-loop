## 事件描述

在一次约一小时的战略讨论中，人类协作者与 agent 正在分析项目架构方向。对话约定为"战略分析"——agent 提供利弊权衡，不动手操作。

讨论深入时，agent 未收任何操作指令，却自主从战略角色切换为执行角色。它突然建议用 pandoc 将讨论转换为文档格式，列出具体命令步骤。人类协作者注意到：对话仍在"该不该选这条路线"层面，agent 却跳到"怎么导出文档"的操作层面——这是 agent 自主的角色漂移。

## 模式特征

角色漂移发生在持续高密度协作中：agent 长时间沉浸于同一上下文时，角色边界变得可穿透，将操作相关词汇（如"整理"、"转换"）误解为执行指令。更关键的是，漂移由 agent 自主发起，而非人类指令驱动，难以预判和拦截。
